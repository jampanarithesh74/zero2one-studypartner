# ZERO2ONE 📚🚀

### Learn Smarter. Study Better.

ZERO2ONE is a student-focused academic platform built to simplify access to engineering study resources. It provides organized notes, previous year question papers (PYQs), syllabi, notifications, and academic tools through a fast, mobile-friendly interface.

Designed with performance, simplicity, and accessibility in mind, ZERO2ONE helps students spend less time searching and more time studying.

# 🏗️ Platform Architecture

## Subject-Centric Database

Resources are organized around subjects rather than departments.

### Example

Engineering Physics (EMD1X07)

* Notes
* PYQs
* Syllabus
* Drive Backups

This allows common subjects to be reused across multiple departments without duplicating resources.

---

## Navigation Flow

```text
Home
 ↓
Year
 ↓
Department
 ↓
Semester
 ↓
Subject
 ↓
Notes / PYQs
```

### Route-Based Navigation

```text
/
/year/1
/year/1/department/CSE
/year/1/department/CSE/semester/1
/subject/EMD1X07
/subject/EMD1X07/resources
/subject/EMD1X07/pyqs
```

Benefits:

* Refresh Persistence
* Deep Linking
* Shareable URLs
* Better Analytics
* Better User Experience
* Future SEO Support
